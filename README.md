# おえかきあて

同じ場所に集まった家族・友人向けの、リアルタイムお絵描き当てゲームです。

- 最大20人
- 4桁の部屋コードで入室
- お題は描き手のスマホにだけ表示
- 絵は全員のスマホにリアルタイム同期
- 正解は口頭（得点なし）
- 描き手は毎回ランダム
- ときどき「しばりルーレット」で変な描きかたを強制される
- ときどき「だんだん見える」ラウンドで、描いている絵がじわじわ公開される
- 描いた順に早送りする「リプレイ」ボタン
- ゲーム終了後、今日の絵を1枚ずつめくる「今日のハイライト」
- 参加者の匿名投票で決める「みんなで決める3大賞」
- QRコードまたは招待リンクから、名前だけで参加
- 通常ラウンドの一部でAIが考えた変なお題に挑む「AIむちゃぶりお題」
- 通常ラウンドの途中でAIがこっそり答えを考える「AIのひみつ予想」
- ゲーム終了後のAI授賞式（OpenAI API設定時）

## オンラインで遊ぶ（Render 無料）

店のPCなしで、家のスマホからURLを開いて遊べます。

### 1. Render アカウント

1. https://render.com を開く
2. **GitHub でサインアップ / ログイン**
3. リポジトリ `kjmanz/testgame` へのアクセスを許可する

### 2. サービスを作る

**方法A（かんたん）**

1. Dashboard → **New** → **Web Service**
2. `kjmanz/testgame` を選ぶ
3. 設定:
   - **Name:** `draw-guess`（任意）
   - **Language:** Node
   - **Branch:** `main`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Instance type:** Free
4. **Deploy** を押す

すでにサービスがある場合は、Build Command を上の内容に直してから **Manual Deploy** してください。

**方法B（Blueprint）**

1. Dashboard → **New** → **Blueprint**
2. `kjmanz/testgame` を選ぶ（`render.yaml` が入っています）
3. そのまま適用して Deploy

### 3. 遊ぶ

1. デプロイ完了後、Render が表示する URL（例: `https://draw-guess-xxxx.onrender.com`）を開く
2. 家族のスマホでも同じ URL を開く
3. 部屋をつくってコードを共有 → 開始

**注意（無料枠）**

- しばらくアクセスがないとスリープします
- スリープ後の最初の1回は、起動に十数秒かかることがあります
- 「読み込み中…」でも少し待てば開きます

## AI機能を有効にする

AI機能はサーバー側の `OPENAI_API_KEY` が設定されているときだけ表示されます。
APIキーがない状態でも、それ以外のゲーム機能はそのまま遊べます。

Render Dashboard で対象サービスを開き、**Environment** に次を設定します。

| Key | Value |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI Platformで発行したAPIキー（Secret） |
| `OPENAI_TEXT_MODEL` | `gpt-5.6-luna`（省略可） |
| `AI_SECRET_GUESS_ENABLED` | `false`でAIのひみつ予想を停止（省略時は有効） |
| `AI_SECRET_GUESS_MAX_PER_GAME` | 1ゲームの最大発生回数。既定2、0〜5 |
| `AI_SECRET_GUESS_RATE_LIMIT` | 接続元ごとの1時間の呼び出し上限。既定30 |
| `AI_GLOBAL_SECRET_GUESS_RATE_LIMIT` | サーバー全体の1時間の呼び出し上限。既定120 |
| `AI_CRAZY_PROMPT_RATE_LIMIT` | AIむちゃぶりお題パック生成の、接続元ごとの1時間の上限。既定12 |
| `AI_GLOBAL_CRAZY_PROMPT_RATE_LIMIT` | AIむちゃぶりお題パック生成の、サーバー全体の1時間の上限。既定50 |
| `FORCE_AI_CRAZY_PROMPT` | `1`で、開発時に対象となる通常・しばりなしラウンドへ強制適用 |
| `APP_ORIGIN` | 公開URLのOrigin（例: `https://draw-guess-bwjm.onrender.com`） |

保存後はRenderが再デプロイします。APIキーはクライアントへ送られず、
ブラウザのコードやGitHubにも含まれません。

AI機能の動き:

**AIむちゃぶりお題**

- 通常・しばりなしラウンドの一部で発生し、リレーなどの特殊ラウンドとは重なりません
- ゲーム開始時に8件のお題パックをまとめて1回生成し、各ラウンドではAPIを呼びません
- 通常設定では1ゲーム最大2回（延長戦を含む）。AI生成に失敗した場合も普通のお題へ自動で戻り、ゲームは続きます
- 正解は「ラーメンを作るペンギン」なら主役の「ペンギン」だけで成立します
- 描画中は描き手だけが全文を見られ、ほかの参加者には「主役を当てよう」と案内します
- 「✅ せいかい！」による答え発表後、主役とAIむちゃぶり全文を全員へ公開します

**AIのひみつ予想**

- 通常・しばりなしラウンドの一部で、描画途中の画像を1枚だけAIが見ます
- 「本命・対抗・大穴」の予想は、描き手が正解を発表するまで全員に秘密です
- 正解はAIへ答えとして教えず、18個のシャッフル済み候補語へ1回だけ混ぜます
- 1ゲーム最大2回が既定で、対象ラウンドにつきAPI呼び出しは最大1回です
- プレイヤー名、部屋コード、プレイヤーIDはOpenAIへ送りません
- AIが遅い・失敗した・利用上限になった場合も、ゲームは止まらず進みます

**AI画伯の授賞式**

- ゲーム終了後、ホストがボタンを押すと最大3作品の授賞式
- 無音のドラムロール演出をはさみ、絵と講評を1作品ずつ大きく発表
- 受賞作では時間無制限で停止し、ホストの「次の賞を発表！」で全員が進行
- 初回もホストの再上映も全端末へ同期し、再接続時は現在の発表位置へ復帰
- 講評は絵の具体的な特徴を拾い、描き手を下げない範囲でクスッと楽しく
- そのゲームの作品（線が引かれているもの・最大24枚）をAIが実際に見て賞を決めます
- OpenAIには描いた人の名前を送信しません
- AI処理に失敗してもゲーム進行には影響しません
- 1ゲームにつきAPI呼び出しは授賞式の1回だけ（やり直しは2回まで）

AIが有効な部屋では、AIのひみつ予想で描画途中の画像1枚と候補語を、
AI授賞式で完成作品画像とお題を、AIむちゃぶりお題では既存のお題から選んだ
主役候補（テキストのみ）をOpenAI APIへ送信します。OpenAIへ送る入力データには、
描いた人の名前、部屋コード、プレイヤーID、APIキーを含めません。APIデータは既定でモデル学習には使われませんが、
不正利用監視ログが最大30日保持される場合があります。個人情報や機密情報は
キャンバスへ描かないでください。

AIむちゃぶりお題を含むこれらのAI機能は共通の `OPENAI_TEXT_MODEL` を使い、標準は
`gpt-5.6-luna` です。APIキーはサーバーだけで保持してください。

公開サービスでは、OpenAI Platform側でもプロジェクトの
**hard spend limit（利用上限）** とアラートを設定してください。
GPT Imageの利用時に403エラーになる場合は、OpenAI Platformで
Organization Verificationの状態も確認してください。

部屋・ギャラリー・AI結果は現在サーバーのメモリ上にあります。
Renderの再起動時には消えるため、残したい絵は端末へ保存してください。

## ローカル起動（開発用）

```bash
npm run install:all
npm run dev
```

AI機能もローカルで試す場合は、サーバーを起動する環境に
`OPENAI_API_KEY` を設定してください。キーを `.env` やソースコードへ
書いてコミットしないでください。

AIのひみつ予想を毎回の通常ラウンドで確認するには、APIキーを設定したうえで
次を実行します。

```bash
npm run dev:ai-secret
```

このスクリプトは`FORCE_AI_SECRET_GUESS=1`、通常ラウンド、しばりなしを設定します。

AIむちゃぶりお題を対象となる通常・しばりなしラウンドで強制確認するには、
APIキーを設定したうえで次を実行します。

```bash
npm run dev:ai-crazy-prompt
```

このスクリプトは `FORCE_AI_CRAZY_PROMPT=1` と通常・しばりなしを設定します。
お題パックが準備できるまでは普通のお題で進み、パック生成に失敗した場合も
ゲームは停止しません。

- クライアント: http://localhost:5173 （空きがなければ 5174 など）
- サーバー: http://localhost:3001

## 遊び方

1. ランダムに選ばれた人がお題を見て描く
2. 他の人は絵を見て口頭で当てる
3. 当たったら描き手が「✅ せいかい！」を押す → 全員の画面にお題が出る
4. 描き手が「つぎのお題へ」
5. 飽きたらホストが「終了」

3の一手間で、聞き取れなかった子にも答えが伝わります。誰も当てられなかった
ときも「せいかい！」で答えを見せてから次へ進みます。

## AIのひみつ予想

通常・しばりなしラウンドの一部では「🤖 AIひみつ予想」が始まります。
最初の線から約7秒後、AIがその時点の絵を1枚だけこっそり見て、
「本命・対抗・大穴」を考えます。予想は描いている途中には表示されず、
描き手が「✅ せいかい！」を押して本当のお題が出たあとに全員へ発表されます。

AIへ渡す18個の候補には本当のお題も1回だけ入りますが、どれが正解かを示す
ラベルは付けず、順番も毎回シャッフルします。予想やコメントは絵の上手・下手を
評価せず、会場を盛り上げるための短い演出です。7秒以内に正解した場合や、
AIが答えられなかった場合も専用の楽しいメッセージだけを表示し、ゲーム進行は
そのまま続きます。個人情報や機密情報はキャンバスへ描かないでください。

## わからないときのパス

お題を知らなかったときは、描き手が「🙅 わからない…パス」を押せます。
ラウンドは進まず（問題数にカウントされず）、**同じ人のまま**お題だけ
引き直します。あてっこ中ならいつでも押せます。

別の人に回さないのは、渡してしまうと「描きたくない」ボタンになるためです。
担当回数も増やさないので、描く人の公平な順番も崩れません。

連打で進まなくなるのを防ぐため、**1ターンに2回まで**です（お題は最大3つ
見られて、3つ目は必ず描く）。残り回数はボタンに出ます。パスしたことは
トーストで全員に伝えます（黙って絵が消えると当てる側が混乱するため）。

**リレー・協力・うそつき・だんだん見える、しばり付きのラウンドでは
パスできません。** ふつうのラウンドだけです。

## しばりルーレット

ふつうのラウンドに、**たまに**「しばり」が付きます（前回から4問はあかず、
そのあと25%の確率。9問あいたら必ず出ます）。しばりの内容は全員の画面に出ます
（見ている側が知らないと、ただ下手な人になってしまうため）。

**リレー・協力・うそつき・だんだん見えるのラウンドには付きません。**
ルールが重なると小中学生には分かりづらくなるためです。

| しばり | 内容 | 止めかた |
| --- | --- | --- |
| 🖐️ 5本しばり | 線は5本まで | サーバーとアプリの両方で止める |
| ✍️ 一筆がき | 指をはなしたら終了 | 同上 |
| ⏱️ 10びょう | 10秒で描ききる | サーバーのタイマー |
| 🖌️ ふとふでペン | ペンが極太になる | サーバーが線の太さを上書き |
| 🙈 めかくし | 描いている本人にだけ絵が見えない | アプリが本人の画面だけ隠す |
| 🤚 ぎゃくの手 | きき手じゃないほうで描く | 自己申告 |
| 🙃 さかさま | 上下ぎゃくむきに描く | 自己申告 |
| 📐 まるきんし | まるい線を使わない | 自己申告 |
| 💗 ハートまぜ | 絵のどこかにハートを描く | 自己申告 |

しばりを出したラウンドはギャラリーにも記録され、AI授賞式でもしばりを
ふまえて賞が選ばれます。

動作確認用に、毎ラウンド必ずしばりを付けて起動できます:

```bash
npm run dev:constraint
```

特定のしばりだけ試すときは `FORCE_CONSTRAINT` にIDを入れます（`blind`、
`speed10`、`lines5` など。IDは `server/constraints.js` 参照）。

## だんだん見える（イントロクイズの絵版）

ときどき出る特殊ラウンドのひとつです。描画開始から、描いている絵が
全員の画面へ1秒または2秒ごとに少しずつ公開されます。わかった人から声に
出して当てます。早い者勝ちなので、いちばん叫び合いになるモードです。

公開方法はラウンドごとに、**描いた順・上から・下から・左から・右から・
中心から・外側から**の7種類からランダムで決まります。公開の間隔は
**1秒ごと**または**2秒ごと**です。「できた！」を押すか20秒になると、
まだ隠れている部分もすべて公開されます。方式・速度・開始時刻はサーバーが
全員へ配るため、途中参加や再接続でも、その時点で公開済みの状態へ同期します。
全部公開したあと、描き手が「せいかい！」を押すと全員へ答えを発表し、
その後にだけ次のお題へ進めます。

動作確認用に、毎ラウンド必ずだんだん見えるにして起動できます:

```bash
npm run dev:gradual
```

## 今日のハイライト

ゲームが終わると、ホストの画面に「🎬 今日のハイライトを見る」が出ます。
押すと全員の画面で同時に、そのゲームで描いた絵が1枚ずつめくられます
（お題と描いた人つき）。白紙のラウンドは飛ばします。

絵はすでに全員の端末のギャラリーにあるため、サーバーは順番だけを配ります。
通常作品は1枚1.8秒、最後の作品は3.2秒です。枚数が多いときは全体が
およそ45秒に収まるよう調整されます。自動再生が一周すると「自由に見返し
タイム」になり、各端末で左右ボタン・左右スワイプを使って好きな作品を
見返せます。見返している位置はほかの参加者へ影響しません。

## みんなで決める3大賞

ゲーム終了後、ホストが「みんなの投票をはじめる」を押すと、参加者全員へ
3つの賞の投票画面が開きます。「じわじわくる賞」「発想が斜め上賞」など、
そのゲームに合う賞が毎回選ばれます。特殊ラウンドの作品が複数ある場合は、
リレーや協力プレーなど専用の賞が入ることもあります。

- 投票先と投票者名は非公開で、途中は投票済み人数だけを表示
- 3つの賞を1作品ずつ選び、同じ作品への二冠・三冠も可能
- 全員が投票すると自動集計。45秒後またはホスト操作でも締め切り
- 同票はすべて受賞。満場一致、1票差、同票、二冠・三冠に合わせて司会コメントが変化
- 集計後は無音のドラムロールをはさみ、絵とコメントを1賞ずつ発表
- 受賞作では自動送りせず、ホストのボタンで全員が次の賞へ進行
- 「みんなでもう一度見る」はホスト操作で全端末へ同期し、再接続にも対応

この授賞式はAI設定なしでも利用できます。投票中に切断しても、締切までに
同じ端末から戻れば続きから参加できます。

## 爆笑リプレイ

「▶ 描いた順にリプレイ」を押すと、その部屋の全員の画面で同時に、
線を描いた順どおりの早送り再生が始まります（2〜5秒）。

早送りが面白いのは、こたえを知ってから「最初のあの丸は何だったのか」が
見えるからです。そのため、ボタンは**こたえを知っている人にだけ**出ます。

| ラウンド | 出る人 | 出るタイミング |
| --- | --- | --- |
| ふつう | 描いた人 | 「せいかい！」で答えを出したあと |
| ⚡ リレー | 描いた人みんな | あてっこタイムに入ってから |
| 🤝 協力 | 描いた人みんな | あてっこタイムに入ってから |
| 🕵️ うそつき | 描いた人・ホスト | こたえあわせのあと |
| 👀 だんだん見える | 描いた人 | 「せいかい！」で答えを出したあと |

当てている最中に全員の画面が白くなると邪魔になるため、それ以外の人からは
押せません（サーバー側でも断ります）。

線のデータは各端末がすでに持っているため、サーバーは合図を配るだけです。
再生が終わると、その間に届いた線もふくめて元の絵に戻ります。
